PhyloIO.jl

PhyloIO — Module
PhyloIO

A small, dependency-free phylogenetic tree type with readers and writers for Newick (including NHX and BEAST/MrBayes [&...] annotations) and the trees block of Nexus files, plus the usual tree queries and edits.

source
using PhyloIO
t = parsenewick("((A:1,B:1)95:2,C:3);")
mrca(t, ["A", "B"])
writenewick(ladderize!(t))

Tree type

PhyloIO.PhyloTree — Type
PhyloTree()

A rooted phylogenetic tree. Nodes are numbered 1:nnodes(tree); each node has a parent (0 for the root), an ordered list of children, a branch length (NaN when missing), a label ("" when missing) and a dictionary of annotations (Dict{Symbol,Any}), which holds support values and anything read from NHX or BEAST-style comments.

Build one with readnewick, parsenewick, readnexus or randtree, or node by node with addnode!.

Reading and writing

PhyloIO.parsenewick — Function
parsenewick(str) -> PhyloTree

Parse one tree in Newick format. Handles quoted labels, branch lengths, numeric internal labels (stored as the :support annotation), [&&NHX:key=value:...] comments and BEAST/MrBayes-style [&key=value,key={a,b}] comments (stored as node annotations; numbers are parsed, {a,b} becomes a vector).

source

Read the first tree (or all trees) from a Newick file. Use parsenewick for a string.

PhyloIO.readnexus — Function
readnexus(path; all=false) -> PhyloTree (or Vector{PhyloTree})

Read trees from the TREES block of a Nexus file (as written by BEAST, MrBayes, RevBayes, FigTree, ...), applying any TRANSLATE table. Node annotations in [&...] comments are kept.

Simulation

PhyloIO.randtree — Function
randtree(n; model=:yule, rng=Random.default_rng(), labels=["t1", …], height=nothing) -> PhyloTree

A random ultrametric tree with n tips. model = :yule gives a pure-birth tree (rate 1); model = :coalescent gives a Kingman coalescent tree. When height is given the tree is rescaled to that root-to-tip distance.
